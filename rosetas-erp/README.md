# rosetas-erp

ERP da equipe: pedidos, clientes, estoque, modelos e preços, produção, equipe.

```bash
npm install
npm run dev     # 5174, com proxy /api -> http://localhost:8080
npm run build
```

Copie `.env.example` para `.env` se quiser mudar variáveis. Em Docker, veja `rosetas-backend/docker-compose.yml`.
