# rosetas-site

Site público (landing + catálogo + pedido + acompanhamento). Sem login.

```bash
npm install
npm run dev     # 5173, com proxy /api -> http://localhost:8080
npm run build
```

Copie `.env.example` para `.env` se quiser mudar variáveis. Em Docker, veja `rosetas-backend/docker-compose.yml`.
